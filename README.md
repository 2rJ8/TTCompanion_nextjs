# Tabletop Companion

Proyecto React organizado por responsabilidades.

## Estructura

```text
src/
├── app/                 # Composición principal de la aplicación
│   └── App.jsx
├── components/          # Componentes reutilizables de la interfaz
│   └── forms/
│       └── TestForm.jsx
├── styles/              # Estilos globales y estilos compartidos
│   └── global.css
└── main.jsx             # Punto de entrada de React
```

Los recursos estáticos propios de la aplicación pueden añadirse en `src/assets/`.
